# artdaq-core-mu2e

Mu2e _artdaq_ Fragment data formats: the code that must be identical in the
online DAQ and in Offline. It defines

- the Mu2e artdaq Fragment type numbers (`TRK`, `CAL`, `CRV`, `DBG`, `DTCEVT`,
  `STM`, `TRKDTC`, `CFO`) and their overlay classes;
- the DTC and CFO DMA packet classes (`DTCLib::DTC_*`, `CFOLib::CFO_*`):
  Data Header, Heartbeat, Data Request, DCS Request/Reply, and the event /
  sub-event / data-block containers the event builder produces;
- per-subsystem payload decoders (tracker, calorimeter, CRV, MobileSync, CFO);
- the art data products `mu2e::EventHeader`, `RunHeader`, `SubRunHeader`.

The wire layouts follow Mu2e-doc-4914. Field-by-field tables, with version
handling and known pitfalls, are in [doc/INTERFACES.md](doc/INTERFACES.md);
a one-page overview is in [doc/ARCHITECTURE.md](doc/ARCHITECTURE.md).

This package is a library only. It ships no executables and opens no ports.

## Building

It is a cetmodules package and builds inside a Mu2e Spack environment that
provides `artdaq-core` (≥ 3.09.00), TRACE, messagefacility, canvas and ROOT:

```bash
spack env activate <mu2e-tdaq-env>
cmake -S artdaq-core-mu2e -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build -j
ctest --test-dir build          # DTC_Event_t, DTC_SubEvent_t (Boost.Test)
```

Debug builds honour `USE_ASAN`, `USE_TSAN`, `USE_UBSAN` and `USE_GCOV`; setting
`BUILD_ROOT_INTERFACE=1` also builds a ROOT dictionary for the `DTCLib`
classes. Doxygen documentation is generated by `doc/CMakeLists.txt` and
includes the Markdown files in `doc/`.

## Using it

```cmake
find_package(artdaq-core-mu2e REQUIRED)
target_link_libraries(my_module PRIVATE artdaq-core-mu2e::Overlays)   # overlays, packets, decoders
target_link_libraries(my_module PRIVATE artdaq-core-mu2e::Data)       # art data products
```

```cpp
#include "artdaq-core-mu2e/Overlays/DTCEventFragment.hh"
mu2e::DTCEventFragment ef(fragment);            // fragment.type() == mu2e::FragmentType::DTCEVT
auto evt = ef.getData();                         // DTCLib::DTC_Event, parsed
for (auto const& blk : evt.GetSubsystemBlocks(DTCLib::DTC_Subsystem_Calorimeter)) { /* ... */ }
```

Header paths under `Overlays/DTC_Packets.h`, `DTC_Types.h` and
`CFO_Packets.h` are deprecated umbrellas; include the per-class headers.
